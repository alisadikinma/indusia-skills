# Reference 04 — Video Format Decision & Master Storyboard

## Project Variable Lock

Examples in this file use **PT INDUSIA (agency) × IRN (client)** as illustrative default. Untuk project lain, substitute:
- `{{agency_name}}` → speaker brand
- `{{client_name}}` → customer/audience subject
- `{{client_fleet_data}}` → "23 truk + 90 chassis" → your client's actual data
- `{{client_pain_pillars}}` → 4 pain pillars yang spesifik untuk client (lihat 02-archetype-routing-hooks.md untuk extract pain dari pakar-logistik-batam atau equivalent domain skill)

Storyboard di bawah = **template re-usable**. Replace placeholders saat produce.

---

## Default Format untuk B2B Proposal Video (Logistik / Fleet Operator)

```
DURASI:        3-4 menit max
ASPECT RATIO:  16:9 horizontal (B2B presentation, embed deck)
              + 1:1 square versi (untuk WhatsApp / LinkedIn share)
RESOLUTION:    1920×1080 master, downscale per platform
DISTRIBUTION:  WhatsApp share ke decision maker, email attachment,
              embed proposal deck PDF link, B2B meeting screen
NARRATION:     Bahasa Indonesia (default), istilah lokal sesuai region client
PURPOSE:       Pre-meeting brief + meeting opener — make decision maker
              paham high-level cara kerja sistem yang akan di-propose
```

## Format Variations Beyond Default

### Variation 1 — Short Social Teaser (60s)

Gunakan kalau Pak Indra share video proposal ke kolega owner trucking lain di WA.

```
0-3s     HOOK (Pattern Interrupt)
3-15s    AGITATE 1 PAIN ONLY (pilih paling resonant — kencing solar)
15-45s   ONE SOLUTION (sensor + AI triangulation)
45-55s   RESULT TEASE
55-60s   CTA + WATCH FULL ("3 lebih banyak: link di bio")
```

### Variation 2 — Pitch Deck Embed (90s)

Untuk paste di slide pitch deck PT INDUSIA saat ke meeting.

```
0-5s     ADDRESS + ESTABLISH CONTEXT ("Konteks IRN: 23 truk di Batam")
5-30s    AGITATE 4 PAIN (compressed 6s each)
30-75s   SOLUTION 4 PILLAR (compressed 11s each)
75-90s   OUTCOME + CTA
```

### Variation 3 — LinkedIn Native (90s)

Untuk LinkedIn share PT INDUSIA's organic content.

Same pace as 90s pitch deck embed, tapi tambah on-screen subtitles (LinkedIn auto-mute play).

### Variation 4 — Detailed Module Deep-Dive (5-7 menit per module, opsional)

Kalau Pak Indra mau detail per fitur setelah lihat 3-4 min main video. Tiap module:
- Module: Anti-Kencing-Solar Detail
- Module: AI Route Optimizer Detail
- Module: ePoD + Auto-Invoice Detail
- Module: Admin Upgrade Detail

Hanya buat kalau diminta. Bukan default.

## Format Decision Matrix

| Use Case | Format Recommended | Duration |
|---|---|---|
| **First proposal video to IRN** ⭐ | 16:9 horizontal full storyboard | **3-4 min** |
| Pak Indra share WA ke kolega | 1:1 or 9:16 vertical teaser | 60s |
| Embed di pitch deck PDF | 16:9 horizontal | 90s |
| LinkedIn organic | 1:1 square + caption | 90s |
| Module deep-dive | 16:9 per module | 5-7 min |
| Public case study (LATER, after IRN signed) | 16:9 + vertical cuts | 90s + 30s + 60s |

## Cinematography Notes (Per Solution Pillar)

### Pillar 1 — Fuel Sensor
- **Lighting:** Documentary natural — kabin truk malam, lampu dashboard
- **Camera:** Handheld + tripod mix, steady di product shot sensor
- **Lens:** 35mm-50mm equivalent (natural perspective)
- **Color:** Industrial-doc desaturated cool tint
- **Music:** Tense build → strategic silence at sensor reveal

### Pillar 2 — AI Route + Auto-Assign
- **Lighting:** Office natural, screen glow on Cici's face
- **Camera:** Static medium shot Cici + screen recording dashboard insert
- **Color:** Slightly warm (office) + clean (dashboard)
- **Music:** Driving documentary 90-110 BPM → uplift saat algorithm match

### Pillar 3 — Driver App + ePoD
- **Lighting:** Daylight customer site
- **Camera:** Driver POV (over-shoulder) + screen recording phone
- **Color:** Documentary natural
- **Music:** Calm acoustic guitar 70-90 BPM

### Pillar 4 — Admin Upgrade
- **Lighting:** Office before-after split
- **Camera:** Static comparison shot (Cici overwhelmed → Cici relaxed)
- **Color:** Before = neutral cold, after = neutral warm subtle
- **Music:** Resolve from tension → calm

### Peak / Won Day
- **Lighting:** Sun-flare allowed (earned hope)
- **Camera:** Wide establishing shot kantor IRN, Pak Indra senyum
- **Color:** Cinematic Hope LUT (RESTRAINED orange-teal, NOT Hollywood action)
- **Music:** Earned uplift, piano + strings building

## Anti-Patterns

❌ **Video >4 menit untuk first proposal** — attention drop. Detail deep-dive di video kedua kalau diminta.

❌ **Stack 4 pain + 4 solution + 4 case study di 1 video 90s** — hectic, gak ada yang landing. Pilih 1 atau 4 (atau bagi).

❌ **Skip pain agitate, langsung jual solusi** — "PT INDUSIA produk our amazing system" = sales-y, audience tutup.

❌ **No specific IRN data** — "perusahaan trucking pada umumnya" = generic. Wajib sebut IRN angka spesifik.

❌ **Slick corporate B-roll dari stock** — gak relate. Wajib actual lapangan footage atau realistic mock.

❌ **AI-generated voiceover Synthesia flat** — terdengar synthetic, kill credibility. Pakai VO actor real Indonesia.

❌ **CTA "klik link di bio"** untuk B2B proposal video — terlalu social-style. Pakai direct phone/email.

❌ **Frame admin reduction sebagai "kurangi karyawan"** — politically risky kalau Cici nonton. Frame "upgrade role".
