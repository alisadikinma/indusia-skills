## 1. The 5-Beat Scaffold (Canonical)

```
┌────────┬───────────────┬────────────────────────────────────┐
│ Beat   │ Runtime Pos   │ Function                           │
├────────┼───────────────┼────────────────────────────────────┤
│ HOOK   │ 0-10%         │ Open curiosity gap, direct address │
│ FORE   │ 10-25%        │ Plant the payoff (Pixar Rule #7)   │
│ BODY   │ 25-70%        │ Show mechanism (3-pillar demo)     │
│ PEAK   │ 70-85%        │ Engineer Insight moment (Heath)    │
│ CTA    │ 85-100%       │ Single soft consultative ask       │
└────────┴───────────────┴────────────────────────────────────┘
```

**Anti-deflation rule:** Peak placement at 70-85% is non-negotiable. Earlier = post-peak deflation hurts CTA. Later = no room for CTA.

**Why 5, not 3 (TikTok Hook-Body-Close) or 15 (Save the Cat):** 5-beat is the minimum viable narrative architecture for 60-240 sec B2B promo that preserves Hook + Foreshadow loop + Pacing engine + Peak + Timed CTA. See `research-output/R1-narrative-framework-deep-report.md` §1.

## 3. HOOK Beat (0-10%) — Operational Rules

### Mechanism
**Curiosity-gap (Loewenstein 1994).** Curiosity intensity = perceived importance × confidence in resolvability.

### Quantified timing
- **First 3 seconds critical** (TikTok, YouTube algorithmic)
- **30-second algorithmic cliff** — retention below platform threshold = distribution penalty

### Rules
1. Visual + audio + curiosity-gap question land **before 3-sec mark**
2. **Specific > vague** — *"Anda tahu jam berapa truk Anda berangkat tadi pagi?"* beats *"Apakah Anda tau kondisi fleet Anda?"*
3. **Owner-pov direct address** — *"Pak, Anda tahu..."* beats *"Para pengusaha trucking sering..."*
4. **Pattern interrupt visual** — first frame unexpected (HP getar bukan office desk)
5. **Indonesian low-arousal register** — calm direct address > shouty "🚨 STOP 🚨" energy

### 7 Owner-Visibility-Gap curiosity-gap hook library
See `02-archetype-routing-hooks.md` Addendum — 7 canonical owner-pov curiosity hooks, one per visibility gap. Use these as starting templates.

### Anti-patterns
- ❌ Hook = brand intro
- ❌ Hook = generic industry problem
- ❌ Hook = aspirational fluff
- ❌ Hook = data dump without gap framing
- ❌ Western high-arousal shouty register for Indonesian Tionghoa B2B owner

## 4. FORESHADOW Beat (10-25%) — Operational Rules

### Mechanism
**Setup-payoff loop (Pixar Rule #7: come up with ending first).** Plant the Peak before BODY mechanism is revealed. Opens Zeigarnik open-loop tension that holds viewer through BODY.

### Rules
1. **Plant the Peak** — drop a hint of what owner will see in Peak (*"owner punya cara baru lihat ini..."*)
2. **Open a sub-loop** (Zeigarnik) — promise unresolved thread BODY will close
3. **Owner-hero framing** (Vogler Writer's Journey Stages 1-4) — owner is protagonist; AI / system is mentor-tool
4. **Articulate conflict** (Sorkin Intention-Obstacle) — owner wants X, obstacle is Y
5. **Narrative transportation onset** (Green-Brock 2000) — viewer shifts from critical-evaluator to story-experiencer

### Anti-patterns
- ❌ Foreshadow = feature list
- ❌ Foreshadow = full mechanism explanation upfront (kills BODY tension)
- ❌ No Foreshadow at all — straight Hook to feature dump
- ❌ Foreshadow contradicts Peak

---

## 5. BODY Beat (25-70%) — Operational Rules

### Mechanism
**Pacing + Drive Shaft + Open Loops.** BODY is sequence of micro-beats (McKee: beat = smallest unit of conflict change). Each shifts viewer state. Sub-loops opened in Foreshadow progressively close (or held for Peak).

### Mandatory inclusions
1. **3-pillar triangulation** — AI + IoT + Mobile mechanism shown, NOT enumerated (LOCK-1)
2. **Asisten demo scene** ≥1 in BODY (LOCK-3) — WhatsApp UI rendering, 8-15 sec runtime, see `04-video-format-decision.md` Addendum §"Mandatory Asisten Demo Scene Spec"
3. **Owner reaction shots** (Heath bros Power of Moments — Insight beat) after each reveal
4. **Concrete data on-screen** — *"B-5678 fuel anomali 15 L jam 9:15"* beats abstract *"fraud detected"*
5. **Conflict escalation beat-to-beat** — first solar reveal → fleet picture → financial implication

### Anti-patterns
- ❌ BODY = static narrated feature list
- ❌ BODY = single scene (no beat structure)
- ❌ BODY >75% runtime (squeezes Peak + CTA)
- ❌ Missing Asisten demo scene (LOCK-3 violation)
- ❌ No 3-pillar anchoring per claim

---

## 6. PEAK Beat (70-85%) — Operational Rules

### Mechanism
**Peak-End Rule (Kahneman 1993, Do et al. 2008, Heath bros 2017).** Retrospective evaluation dominated by (peak intensity + end moment). Duration is neglected.

Heath bros operationalize: Peaks engineered via **Elevation / Insight / Pride / Connection**. For B2B owner promo, canonical Peak = **Insight + Pride** (owner sees ops in new way, feels in-control).

### Rules
1. **Place at 70-85% runtime** — earlier deflates, later squeezes CTA
2. **Engineer Insight moment** — owner says or face shows realization: *"Saya bisa lihat semua dari HP saya"*
3. **Single emotional moment, not multiple** (Kahneman peak-singularity)
4. **Sensory specificity** (Truby Symbol Web) — specific concrete image (HP getar at magrib; gold ETA dashboard)
5. **Don't over-explain** — let visual + reaction carry it; voiceover light or absent

### Peak design library

| Pattern | Visual | Reaction |
|---|---|---|
| Vindication | owner reading Asisten reply | Quiet smile + nod |
| Insight | Dashboard overlay reveal | Eyebrow rise + pause |
| Control-regained | Owner thumb-ups Y to invoice hold | Decisive tap |
| Family-business pride | Anak/menantu watching owner navigate | Mutual look of respect |
| Crane-trucking synergy moment | Both vehicle types on screen, single map | owner widening view |

### Anti-patterns
- ❌ Peak = feature crescendo (10 features named)
- ❌ Multiple peaks averaged out
- ❌ Peak too early (50%)
- ❌ No reaction shot — viewer doesn't know to feel
- ❌ Heavy voiceover at Peak — kills emotional moment

## 7. CTA Beat (85-100%) — Operational Rules

### Mechanism
**Empirical timing (Wistia 36k CTA study) + personalization (HubSpot 330k CTA study) + Indonesian Tionghoa SME register.**

### Rules
1. **CTA in last 10-15%** of runtime (Wistia — for ≤5 min B2B promo)
2. **In-video CTA, not separate landing** (HubSpot: +380% vs sidebar)
3. **Single CTA, not multi** (HubSpot: +32% single-CTA pages)
4. **Soft consultative for Tionghoa B2B SME** — *"DM untuk diskusi"* > *"BELI SEKARANG"*
5. **Personalized** — name addressed, specific industry context (HubSpot +202%)
6. **CTA card on-screen with copy + visual** (TikTok BP: +45% recall, +65% brand affinity)

### CTA copy library per audience

| Audience | CTA Copy |
|---|---|
| owner owner Tionghoa SME | *"Pak, DM kami untuk demo Asisten — gratis, 30 menit. Tidak ada paksaan."* |
| Procurement / IT manager (B2B corporate) | *"Request proposal di [URL]"* |
| Sopir / karyawan (recruitment video) | *"Daftar di [link], kami panggil interview"* |
| Customer (tracking-app promo) | *"Scan QR, dapatkan link tracking"* |

### Anti-patterns
- ❌ Hard-sell ("BELI SEKARANG!" / "JANGAN SAMPAI KETINGGALAN!") in Tionghoa SME register
- ❌ Multiple CTAs ("DM atau email atau visit...")
- ❌ CTA before Peak (deflation)
- ❌ CTA in last 5% (algorithmic risk if viewer doesn't reach)
- ❌ CTA copy without next-step clarity

## 9. Beat Veto Checklist (Apply Before Producing)

Run through this checklist on every video brief before script finalize:

```
HOOK
  [ ] Curiosity-gap delivered before 3 seconds?
  [ ] Owner-pov direct address ("Anda Pak...")?
  [ ] Specific data, not vague?
  [ ] Calm register, not shouty?

FORESHADOW
  [ ] Peak planted before mechanism revealed?
  [ ] Sub-loop opened (Zeigarnik)?
  [ ] Owner as hero, system as mentor-tool?
  [ ] Conflict articulated (Intention-Obstacle)?

BODY
  [ ] 3-pillar triangulation (AI + IoT + Mobile)?
  [ ] Asisten demo scene present (≥1, 8-15s)?
  [ ] Owner reaction shots after reveals?
  [ ] Concrete data on screen?
  [ ] Conflict escalation beat-to-beat?

PEAK
  [ ] Placed at 70-85% runtime?
  [ ] Insight moment engineered (Heath bros)?
  [ ] Single emotional moment (not multiple)?
  [ ] Sensory specific?
  [ ] Light voiceover?

CTA
  [ ] In last 10-15% of runtime?
  [ ] In-video, not sidebar?
  [ ] Single CTA, not multi?
  [ ] Soft consultative for Tionghoa SME (or appropriate per audience)?
  [ ] Personalized + next-step clear?

LOCK CASCADE
  [ ] Owner Visibility Gap anchored in Hook (LOCK-2)?
  [ ] 3-pillar triangulated in BODY (LOCK-1)?
  [ ] Asisten demo present (LOCK-3)?
  [ ] Tionghoa owner default register (LOCK-4) OR alternate per audience?
  [ ] 2-layer cultural model respected (LOCK-5) — if cross-layer surface, anti-fraud-with-dignity framing?
```

If ≥3 ❌ → rewrite. ≥6 ❌ → throw out, restart from Hook.
