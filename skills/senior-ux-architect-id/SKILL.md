## Anti-Patterns

❌ **Material Design defaults without Indonesian calibration** — colors, iconography, copy decks all need pass through Indonesian filter
❌ **Single "Indonesian user" persona** — always split Owner (Tionghoa default) vs Karyawan (Indonesian general)
❌ **Text-first workflows for sopir** — voice-note alternative mandatory
❌ **Hard-confrontation error messages** — face-saving framing mandatory ("Coba lagi ya Pak" not "Error: invalid input")
❌ **Onboarding via 30-min tutorial video** — zero-training test fails. Design for WhatsApp-pattern adoption.
❌ **Honorific stripped to "Anda" generic** — preserve specific honorific (Pak/Cik/Koh/Bapak/Mas) per layer
❌ **English UI defaults** — Bahasa Indonesia first, English code-switch for technical terms only
❌ **Western emoji set in formal owner-facing surface** — emoji conservative for B2B Tionghoa register; OK for sopir-facing
