# 03 — Creative Ideation Engine (Out-of-the-Box Models)

The skill's job is to escape the SaaS-subscription default. This is the generator. Run ≥2 techniques per brief to force a spread of non-obvious models, then converge using `01` (patterns) and `02` (economics).

**Rule:** never present one model. Generate 6–10 candidates, then shortlist ≥3 distinct, ≥1 non-SaaS (Iron Law).

---

## A. The 12 generator techniques

1. **Value-metric swap** — list 5 things you *could* meter (seats, usage, units processed, outcomes, value/savings created). Force a model around each non-seat one. Often the winning model is hiding in metric #4 or #5.
2. **Inversion** — flip the default. "What if the customer paid nothing upfront and we took a cut of savings?" (gainshare/BOTT, per Acquis). "What if the hardware were free and the intelligence recurring?" (razor-blades / EaaS).
3. **Cross-industry transplant** — steal a model from a far industry: insurance (risk-pooling), utilities (metered + standing charge), film (royalties/windowing), fitness (class-pack credits), elevators (EaaS uptime contracts), SaaS-marketplace (take-rate). Map onto {{ai_capability}}.
4. **CapEx ⇄ OpEx switch** — take any one-off sale and convert to recurring (EaaS, per Bain) — or take a subscription and convert to a capex appliance + light recurring for on-prem buyers. Two models from one capability.
5. **Unbundle / rebundle** — split the offer into atoms (model, data, integration, support, hardware, outcomes) and price each differently; then rebundle the atoms competitors *can't* assemble.
6. **Who-else-benefits (third-party payer)** — the user isn't always the payer. Could an insurer, supplier, channel, or platform pay because they capture value too? (e.g. embedded-finance attach, supplier-funded, marketplace-subsidized.)
7. **Free-the-core, tax-the-edge** — give the commoditizing core away; monetize the defensible edge (data, integration, outcomes, distribution). Counter to "AI wrapper" fragility (per Jimo).
8. **Outcome reframe** — restate the offer as the business result, not the software. "We don't sell inspection software; we sell *zero-escape defects at $X/board*." Unlocks outcome/per-unit/gainshare pricing.
9. **Labor-cost reframe** — price an agent against the *loaded cost of the human work it replaces*, not against software comps. Reframes budget from IT line to labor line (per Paid.ai agent-based archetype).
10. **Ecosystem / picks-and-shovels** — instead of selling the end solution, sell the enabling layer to everyone building solutions (tooling, no-code editor, model-as-asset, white-label engine).
11. **Time/territory windowing** — sell exclusivity by vertical, region, or time window (capability leasing, franchise-operator). Same asset, multiplied capture.
12. **Constraint removal** — name the buyer's hardest blocker (capex, risk, no in-house talent, procurement) and design the model *around removing it*: paid pilot, risk-share guarantee, BOT, profit-share-on-own-ops. The model becomes the adoption unlock.

## B. Recombination matrix

Cross **value metric** × **mechanism** × **structure** to manufacture candidates fast:

| Value metric | × Mechanism | × Structure |
|---|---|---|
| units processed | usage + floor/cap | direct |
| outcomes/results | outcome / gainshare | channel / reseller |
| FTEs saved | per-agent / per-FTE | white-label / OEM |
| savings created | gainshare % | JV / NewCo |
| hardware+AI bundle | EaaS / deploy+recurring | build-operate-transfer |
| data/benchmarks | subscription / API | profit-share-on-own-ops |

Pick one cell from each column → a coherent candidate model. Generate 6 by walking diagonals.

---

## C. Anti-model check (kill the obvious losers early)

For each candidate, ask:
- Does value scale with the metric? (else → metric error)
- Positive contribution margin after inference COGS? (else → margin trap, see `02`)
- Does it build a moat (data/workflow/distribution)? (else → copyable discount)
- Can the buyer actually *buy* it without a 6-month fight? (else → add a land SKU)
- Who owns data + IP after? (decisive for partnerships, see `05`)

Survivors go to the options table. Score and stress-test in `06`.
